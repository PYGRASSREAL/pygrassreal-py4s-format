## 2. ข้อความสำหรับกรอก "ลักษณะผลงานโดยย่อ" (สามารถ Copy ไปวางในระบบได้ทันที)

```text
ผลงานโปรแกรมคอมพิวเตอร์และโครงสร้างข้อมูล PyGrassReal 4D Dynamic Splat (นามสกุล .py4s) เป็นนวัตกรรมรูปแบบไฟล์คอนเทนเนอร์เดี่ยว (Single-Container Format) สำหรับเทคโนโลยี 4D Gaussian Splatting (4DGS) เพื่อแก้ไขปัญหาไฟล์ 4DGS ในอุตสาหกรรมคอมพิวเตอร์กราฟิกส์เดิมที่ไฟล์มีขนาดใหญ่ ข้อมูลการเคลื่อนไหวเชิงมิติเวลากระจัดกระจาย และขาดข้อมูลโครงสร้างการตรวจจับการชนทางฟิสิกส์ (Physics Collision) ที่เคลื่อนไหวตามวัตถุได้จริง

โครงสร้างไฟล์ประกอบด้วยส่วนหัวคงที่ขนาด 128 ไบต์ (Fixed Binary Header) กำกับด้วยค่า Magic String "PY4S" (0x50 0x59 0x34 0x53) ทำหน้าที่จัดสรรตำแหน่งหน่วยความจำและเชื่อมโยงองค์ประกอบสำคัญเชิงมิติเวลาเข้าด้วยกันในไฟล์เดียว ได้แก่:
1. ข้อมูลฐานภาพเสมือนจริงสามมิติต้นแบบแบบ 3D Gaussian Splatting (.spz) ที่ผ่านการบีบอัดแบบไม่สูญเสียความละเอียด
2. โครงสร้างข้อมูลน้ำหนักและระนาบการแปลงรูปทรงเชิงมิติเวลา (HexPlane Neural Deformation Weights & Temporal Keyframes) ที่เชื่อมต่อมิติเวลา t กับการเคลื่อนที่และการหมุนของจุดคลาวด์
3. ข้อมูลรูปทรงเรขาคณิตสำหรับตรวจจับการชนทางฟิสิกส์ที่เปลี่ยนรูปทรงได้แบบเรียลไทม์ (Deformable Physics Collider Hitbox) ผ่านอัลกอริทึมการกระจายแรงและการเคลื่อนที่แบบ K-Nearest Neighbors (KNN) ร่วมกับ Inverse Distance Weighting
4. ข้อมูลเมทาดาทาโครงสร้างการเล่น อัตราเฟรมต่อวินาที (FPS) ขอบเขตขนาด และความสัมพันธ์เชิงมิติเวลา (Spatiotemporal JSON Metadata)
5. ข้อมูลภาพเคลื่อนไหวตัวอย่าง (Animated Preview)

ผลงานนี้ครอบคลุมข้อกำหนดโครงสร้างทางเทคนิค (Specification) และชุดซอร์สโค้ดต้นฉบับในการเข้ารหัสและถอดรหัส (Codec Implementation) ในภาษา C++, Python และ TypeScript ซึ่งรองรับการทำงานร่วมกับ Unreal Engine 5, เว็บเบราว์เซอร์ และระบบจำลองฟิสิกส์กราฟิกสี่มิติ
```

## 3. เอกสารและไฟล์ที่ต้องแนบในระบบ e-Services
1. **สำเนาบัตรประจำตัวประชาชน** ของผู้สร้างสรรค์/เจ้าของลิขสิทธิ์ (หรือหนังสือรับรองนิติบุคคลหากยื่นในนามบริษัท)
2. **ไฟล์ข้อกำหนดเชิงเทคนิค (Specification):** แปลงไฟล์ `SPECIFICATION.md` เป็น PDF
3. **ไฟล์ซอร์สโค้ดต้นฉบับ:** รวมซอร์สโค้ดต้นฉบับ ได้แก่:
   - `cpp/Py4sFormat.h`
   - `cpp/Py4sReader.cpp`
   - `cpp/Py4sWriter.cpp`
   - `python/py4s_codec.py`
   - `typescript/py4sCodec.ts`  
   แปลงเป็นไฟล์ PDF (ประมาณ 20-35 หน้า พร้อมระบุข้อความหัวกระดาษลิขสิทธิ์ "PyGrassReal 4D Splat (.py4s) Source Code - Copyright (c) 2026 PyGrassReal AI")
4. **ลิงก์อ้างอิงสาธารณะ:** ระบุ URL ของ GitHub Repository (เช่น `https://github.com/PYGRASSREAL/pygrassreal-py4s-format`) เพื่อใช้เป็นหลักฐานแสดงการเปิดเผยและเผยแพร่ครั้งแรก (First Publication)
